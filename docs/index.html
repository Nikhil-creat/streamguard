StreamGuardDesigned & Developed by NIKHIL CHARY SRIRAMOJU

Fraud caught while the transaction is still in flight.

StreamGuard ingests payment events through Kafka, scores them with a CNN, rules and a graph signal, lands them in a Delta Lake medallion, and hands every flagged case to an AI agent that investigates it using RAG over fraud playbooks.

What is inside

Hybrid scoringCNN over card sequences, a rule engine, and a graph signal blended into one risk score.
Agentic investigatorLangGraph agent with SQL, RAG and action tools. It plans, retrieves, reflects, then decides.
Reliable storageDelta Lake gives ACID writes, schema enforcement and time travel for audits.
Tested transformationsdbt models with tests and lineage docs, scheduled hourly by Airflow.
Drift and retrainingAirflow checks score drift and retrains the CNN on analyst-confirmed labels.
ExplainabilityHeatmap of the cells that drove each score, so analysts see why a case was flagged.
ObservabilityPrometheus metrics and Grafana dashboards for lag, latency and flag rate.
GovernanceCard tokenization, an audit trail of agent decisions, and human approval for blocks.
